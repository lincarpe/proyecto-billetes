# 01 · Git y GitHub

> Esta carpeta es un índice. El código y los documentos viven en `src/`, `api/`, `notebooks/` y `docs/`.

## Qué se hizo

El proyecto está en un repositorio privado de GitHub: https://github.com/lincarpe/proyecto-billetes

- Los commits son pequeños, uno por cambio, con prefijos convencionales (`feat:`, `docs:`, `chore:`, `fix:`, `refactor:`).
- Los datos procesados, los modelos entrenados y el entorno `.venv` no se suben a Git.

## Dónde está

| Qué | Dónde |
|---|---|
| Archivos que Git no sube | [`.gitignore`](../.gitignore) |
| Plantilla de pull request | [`.github/pull_request_template.md`](../.github/pull_request_template.md) |

## Límite

El proyecto lo hizo una sola persona, así que el historial tiene un solo autor y no hay pull requests de revisión entre integrantes.
